Evidence

Our user stories describe the features learners, parents, and teachers need in the BrightStart website. Each story follows the format As a [role], I want [feature], so that [benefit] and includes acceptance criteria to explain what must be achieved for the story to be considered complete. We broke the user stories into smaller tasks and managed them using our Trello Kanban board. The Trello board helps us track task progress and responsibilities throughout the project.

US-01: Learn about the service

As a parent or learner, I want to read about BrightStart and its services, so that I can decide whether it suits me.

Acceptance criteria: Home, About Us and Services pages exist; navigation links work between them.
